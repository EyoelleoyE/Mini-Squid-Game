# Squid Game: Glass Bridge (C++ Terminal Game) 🎮

A simple, choice-based terminal adventure game built in C++. This was my first checkpoint project where I applied logic, loops, and randomization.

## 📖 The Story
You have been abducted and placed at the start of a deadly glass bridge. To win $1,000,000, you must cross 5 sections of the bridge. Each section has two glass panes: one is tempered (safe), and the other will break (game over). 

## 🛠️ Features
*   **Randomized Levels:** Every game is different because the "safe" door is generated randomly.
*   **Input Validation:** The game handles incorrect inputs if you type something other than the options provided.
*   **Restart Logic:** If you lose, you can choose to try again or exit the program.
